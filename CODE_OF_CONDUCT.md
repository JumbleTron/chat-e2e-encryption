# Code of Conduct

Współtworzymy projekt w sposób rzeczowy i profesjonalny. Oczekujemy szacunku, technicznej argumentacji, otwartości na korektę oraz oddzielania krytyki kodu od oceny osoby.

Niedopuszczalne są nękanie, groźby, dyskryminacja, publikowanie cudzych danych prywatnych oraz celowe zakłócanie pracy projektu. Maintainerzy mogą edytować lub usuwać treści i ograniczać udział osób naruszających te zasady.

Problemy dotyczące zachowania można zgłaszać prywatnie maintainerom repozytorium. Zgłoszenia będą rozpatrywane z zachowaniem poufności w zakresie możliwym dla platformy GitHub.
